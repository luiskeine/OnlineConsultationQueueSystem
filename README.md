# Online Consultation Queue System 🏥

A persistent, database-driven queue management system built with Java Swing and MySQL.

## ✨ Current Features
- **Role-Based Access Control:** Secure login for Admins and Clients.
- **Real-time Synchronization:** Admin, Client, and Lobby panels stay synced via database polling.
- **Priority Logic:** Automatically prioritizes Emergency tickets over Regular ones.
- **Persistent Storage:** All data is stored in a MySQL database.

## 🛠 Tech Stack
- **Language:** Java 17+
- **GUI:** Java Swing
- **Database:** MySQL 8.0
- **Version Control:** Git & GitHub
